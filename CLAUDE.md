# Unmuted - AI Marketing Project

## How this works

Before doing ANY marketing task, ALWAYS read `Context Engine/unmuted-context.md` first. This file contains the brand context - who the company is, who they sell to, what they stand for, and how they talk.

Every piece of content, every analysis, every recommendation starts from the context file.

## Project structure

- `Context Engine/` - Source materials and brand context. Add transcripts, research docs, or other reference materials here.
- `Blogs/` - Generated blog posts and focus group feedback.

## Rules

- Read Context Engine/unmuted-context.md before every task
- Only use verified information from the context file - never invent facts
- Match the tone of voice described in the context file
- If information is missing, say so - don't fill in gaps with assumptions
- No em dashes
- Blog posts go in the `Blogs/` folder
